        Project Documentation & Threat Reference

        Learn more about ThreatScope, the importance of email forensics, and detailed definitions of our evaluation rules.

        Why Analyze Email Headers & Bodies?

        Emails are the number one vector for cyber attacks, phishing, Business Email Compromise (BEC), and malware delivery. Organizations and individuals are constantly targeted by spoofed identities. Standard email clients hide the raw technical headers and underlying structure of the email, preventing users from seeing how a message was routed.

        Email Header Analysis parses the server routing hops, originating IP addresses, and authentication verification records (SPF, DKIM, DMARC) to verify if the sender is legitimate. **MIME body parsing** extracts hidden URLs and attachments to run deep inspections (homoglyphs, macro checks, double extensions, and reputational scanning).

        Core Checkpoints Reference

        ThreatScope processes every analyzed email through four comprehensive security checkpoints:

        • Checkpoint A: Identity & Authentication - Evaluates SPF, DKIM, and DMARC alignments, Envelope-to-Header spoofing, domain MX records validation, and time-zone routing anomalies.
        • Checkpoint B: Content & URLs - Scans the body blocks for hidden URL destinations (phishing redirections), IDN Homoglyph (Punycode) character disguises, and urgent financial BEC text pattern matches.
        • Checkpoint C: Attachments - Recursively scans files for double extensions, verifies format discrepancies using magic bytes, and inspects Office documents for macros executing shell commands.
        • Checkpoint D: Threat Intelligence - Queries external databases to check domain registration age via RDAP and IOC reputations using VirusTotal signatures.

        Heuristic Rules Engine Definitions

        SPF (Sender Policy Framework)

        Verifies if the sending mail server is authorized to send emails on behalf of the sender's domain. A FAIL adds 30 penalty points. A missing record adds 10 points.

        DKIM (DomainKeys Identified Mail)

        Provides a cryptographic signature ensuring that the email content has not been altered in transit. A signature validation FAIL adds 30 penalty points.

        DMARC (Domain-based Message Authentication)

        Uses SPF and DKIM alignments to specify how receivers should handle failures. A DMARC validation FAIL adds 40 points; a missing record adds 10 points.

        Envelope-to-Header Alignment

        Checks if the Return-Path (SMTP MAIL FROM) domain aligns with the visible From header. Mismatches often indicate spoofing (+20 points).

        Time-Zone Anomaly

        Computes the difference between the Date header and the first Received hop timestamp. Discrepancies exceeding 1 hour add 15 points.

        Domain MX Records Check

        Validates if the sender's domain has active Mail Exchange (MX) records. Domains without MX records are likely fake (+10 points).

        Reply-To Domain Mismatch

        Checks if the Reply-To header points to a completely different domain than the From header (e.g. From: exec@company.com, Reply-To: exec@gmail.com). Common in phishing (+30 points).

        Message-ID Anomaly

        Checks if Message-ID exists, is malformed, or doesn't align with From or sending hop domains (+10 points).

        Hidden Link Destination

        Flags links where the visible anchor text mimics a legitimate domain but the actual href points to a different destination (+25 points).

        Homoglyph (Punycode) URLs

        Detects Internationalized Domain Names (IDNs) starting with xn-- designed to mimic English characters to deceive users (+30 points).

        BEC NLP Urgency Analyzer

        Flags emails displaying concurrent urgent language and financial keywords (wire transfer, gift card, etc.) (+40 points).

        Zero-Width Character Obfuscation

        Detects invisible Unicode characters (such as U+200B) hidden inside text or URL strings to bypass filters (+20 points).

        Double Extension Attachments

        Flags files designed to mimic documents but containing executable binaries, such as invoice.pdf.exe (+30 points).

        Magic Bytes Mismatch

        Inspects the raw starting bytes of attachments to verify if their real file format matches the extension claim (+40 points).

        Office Macro Scan

        Deconstructs Office documents to detect VBA project folders and keywords executing commands like WScript, shell, or PowerShell (+35 points).

        Domain Reputation Heuristics

        Checks the sender domain for typosquatting, DGA name randomness, and Punycode spoofing indicators (+40 points).

        IOC Reputation Heuristics

        Performs a structural analysis on all extracted links and attachment names to detect phishing keyword matches, dangerous file extensions, and brand impersonation (+40 points).

        VirusTotal Reputation Check

        Checks files and URLs against VirusTotal's multi-antivirus scanners. Any positive detections add 50 penalty points (optional, key-dependent).

        Risk Scoring & Verdict Thresholds

        ThreatScope aggregates penalty points from all triggered heuristic rules. The final score (capped at 100) dictates the Secure Email Gateway (SEG) verdict:

        0 - 15 Clean

        Delivered to inbox normally. Represents a legitimate email that passed core authenticity and structural integrity checks.

        16 - 44 Suspicious

        Delivered with a warning banner prepended to the email body. Advise users to proceed with caution when clicking links or downloading attachments.

        45 - 79 Quarantine

        Routed to the spam/junk folder or quarantined. Held in the Secure Email Gateway for a Security Operations Center (SOC) analyst to manually inspect.

        80+ Reject

        Dropped immediately at the gateway. Blocked before delivery; the recipient never sees the email. Reserved for clear, confirmed spoofing and malware exploits.
